# Modelo de recursos

No se añaden tablas. Los recursos configuration/structure se generan desde un proyecto autorizado. Los análisis son resultados inmutables de la caché existente, indexados dentro del runtime de cada proyecto. El catálogo expone dos recursos por proyecto; la plantilla permite consultar análisis por ID sin enumerar resultados efímeros. Páginas de hasta 50 entradas ordenadas por URI; cursor = último URI entregado. Un catálogo cambiante no constituye una instantánea transaccional.
